一、行业本质：券商到底是什么生意
一句话定义
券商是A股交易和融资活动的"过路费收取者"+ "自营资金的杠杆放大器"。它不创造价值，它分享市场活跃度。

三个底层属性，决定了一切

属性1：强周期，β特征极强
牛市券商利润可以涨3-5倍，熊市跌70-80%。全行业利润和"市场总成交额×平均换手率"高度相关。
这意味着择时比选股重要——选错时点，再好的券商也会亏。
属性2：业绩高度同质化
50家上市券商做的事情大同小异（经纪+投行+自营+资管+信用）。真正的差异只在两点：①业务结构权重不同 ②对周期的杠杆系数不同。
这意味着单只券商α有限，更多时候是"选风格"而不是"选公司"。
属性3：重资产+高杠杆+强监管
券商资产负债表里70-80%是金融资产（自营持仓）。杠杆约3-5倍（受监管限制，远低于银行的10倍）。强监管意味着政策一变（如降佣金、限自营、控分红），全行业ROE中枢就移动。
核心公式
券商利润 = (经纪佣金 + 投行收入 + 资管费 + 信用利差) + 自营投资收益 - 减值损失
= 流量业务（受市场活跃度驱动）+ 自营业务（受股债涨跌驱动）
理解这个公式，就理解了券商的全部脉络。
二、五大业务线：每条线的驱动因子与脾气
业务1：经纪业务（收过路费）
占比20-25%
本质：散户/机构买卖股票，券商收万分之2-5的佣金。
驱动因子：A股日均成交额 × 平均佣金率。
周期性：强β。日均成交从1万亿→2万亿，经纪收入翻倍。
长期趋势：结构性下行。佣金率从2010年的万8降到现在万2.5，未来还会降。
量化锚点：日均成交每+1000亿 → 板块净利+3-5%。
关键判断：短期看日均成交额；中期看居民储蓄→股市的"搬家"趋势；长期看佣金率会不会跌破成本线。
业务2：投行业务（项目制收入）
占比10-15%
本质：帮企业IPO、再融资、并购，按项目大小收承销保荐费。
驱动因子：IPO节奏 + 再融资规模 + 并购重组活跃度。
周期性：政策周期为主，市场周期为辅。注册制收紧时全行业冰封。
长期趋势：A股注册制+退市制度→投行成为决定龙头地位的关键变量。
量化锚点：IPO月度募资每+100亿 → 投行型券商净利+1-2%。
为什么投行重要：这是A股券商唯一能讲"长期结构性成长"故事的业务。其他业务都是周期性的。
业务3：自营业务（券商自己的钱炒股炒债）
占比30-40% · 最大变数
本质：用券商自有资金+融资资金，投资股票/债券/衍生品。
驱动因子：A股涨跌 + 债市利率 + 衍生品对冲。
周期性：极强，且方向不可预测。
量化锚点：沪深300每涨10% → 板块净利+15-20%；10Y国债收益率每降10bp → 自营投资收益+3-5%。
关键判断：股债双牛是券商利润大年的必要条件（如2014、2020、2024年）。股债双杀是券商利润大灾的必要条件（如2018、2022年）。
为什么这块最关键：行业利润的边际变化主要来自这块。Q1业绩反弹50%，大概率是自营贡献了60-70%的增量。
业务4：资管业务（管理费收入）
占比10-15%
本质：公募基金子公司+资管计划，收管理费。
驱动因子：AUM规模 × 平均费率。
周期性：弱（AUM不会快速下降），但费率被持续压制。
长期趋势：结构性承压。基金费率改革三步走，每步都降10-20%。
量化锚点：管理费率每降10bp → 资管型券商净利-2-3%。
业务5：信用业务（融资融券+股票质押）
占比10-15%
本质：借钱给客户买股票（两融）或抵押股票借钱（质押）。
驱动因子：两融余额 + 质押规模 + 利差。
周期性：中等。两融跟着行情走，质押有滞后。
量化锚点：两融每+1000亿 → 板块净利+1-2%。
关键判断：两融余额是市场风险偏好的同步指标。质押爆仓是熊市末期的重要预警。

三、行业演化史：理解今天必须先理解过去20年
阶段一：通道时代（2000-2014）
经纪占比70%+，自营是辅助。ROE中枢8-12%（牛市能到20%）。核心矛盾：通道业务同质化，无差异竞争。标志事件：2008年牛市券商利润历史峰值。
阶段二：资本中介时代（2014-2020）
经纪占比降到30%，自营+信用业务崛起。ROE中枢6-10%。核心矛盾：资本金竞赛，谁有钱谁加杠杆做自营。标志事件：2015年牛市、2018年股票质押风险。
阶段三：财富管理+投行专业化时代（2020至今）
自营占比40%+，资管和投行成为差异化关键。ROE中枢5-8%（持续下移）。核心矛盾：佣金率+管理费+承销费三杀，靠规模和效率撑利润。标志事件：2023年公募基金费率改革、2024-25年券商合并潮。
为什么ROE中枢一直在降？
1. 价格端：佣金率从万8→万2.5，管理费从1.5%→0.5%，承销费率从5%→3%
2. 成本端：合规、IT、风控投入越来越重，人员成本居高不下
3. 资本端：监管要求净资本越来越厚，分母变大压低ROE
这意味着：用2014年的15%ROE中枢去推导今天的合理PB是错误的。今天的合理PB可能就是1.0-1.3x，不是1.5-2.0x。

三轮整合潮

整合潮时间驱动典型案例
第一轮2004-2006综合治理中信收购万通、广发借壳延边公路
第二轮2014-2016资本市场改革申万+宏源、国泰君安H股回归
第三轮2024至今航母级券商政策国泰+海通、国联+民生、中金+信达、平安+方正
第三轮特点
自上而下、国资主导、按系统整合。汇金系、平安系、地方国资系各自整合。
四、券商分类：五种商业模式，五种不同生物

不是所有券商都是一回事。理解分类，才能理解为什么同样PE 10x，有的便宜有的不便宜。

类型1：综合龙头（中信、华泰、国泰海通）
全牌照、规模大、业务均衡。α来源：规模效应+品牌+人才储备。β特征：跟随板块，弹性中等。
合理估值：PE 11-13x、PB 1.2-1.5x。看什么：净资产排名、ROE能否守住8%。
类型2：投行型（中金、中信建投）
投行+国际业务占比高，自营也强。α来源：高净值客户+海外渠道+大型IPO份额。β特征：弹性比综合龙头大。
合理估值：历史上享有PE溢价（15-20x），现在被压到14x左右。看什么：IPO份额、跨境业务收入。
类型3：经纪型（银河、国信）
营业部多、散户基础大。α来源：网点+客户粘性。β特征：日均成交的纯β标的。
合理估值：PE 9-11x、PB 1.0-1.2x。看什么：日均成交额、新增客户数。
类型4：资管型（广发、华泰）
参控股大型公募基金，资管收入占比高。α来源：基金子公司管理规模和品牌。β特征：相对稳定。
合理估值：历史上享有PE溢价，但费率改革后溢价被压缩。看什么：基金子公司AUM、费率变化。
类型5：互联网型（东方财富）
流量驱动，低成本运营，但本质还是券商。α来源：流量+低成本+代销。β特征：弹性最大（流量股属性）。
合理估值：不能用传统券商PE比，应该用互联网/平台型估值（PE 20-40x）。看什么：日活、代销规模、市占率。
类型6（特殊）：整合主题型
自身体量不大，但是合并案的标的。α来源：合并溢价。β特征：事件驱动，跟板块β弱相关。
合理估值：套利空间决定（接近换股价为合理）。看什么：合并进度、审批节点。
五、判断框架：怎么看券商板块的当前状态

第一步：判断β（板块大方向）

问三个问题
1. 市场处于什么周期？
牛市初期 → 全板块多头，重仓 | 牛市中后期 → 卖出，泡沫化 | 熊市 → 全板块空头 | 震荡市 → 选结构（投行型/资管型胜出）

2. 流动性环境？
货币宽松 + 股债双牛 → 自营利润大年 | 紧缩 + 股债双弱 → 自营利润大灾 | 单边宽松 → 看结构

3. 政策方向？
鼓励直接融资 → 投行型受益 | 打击佣金/费率 → 全板块ROE压制 | 鼓励合并 → 整合主题受益

第二步：判断估值水位

三个估值锚
1. PE-TTM分位：>70%偏贵、30-70%中性、<30%偏便宜（但要警惕"估值陷阱"）
2. PB分位 + ROE趋势：PB低+ROE回升=真便宜，PB低+ROE下降=价值陷阱
3. 板块vs沪深300相对估值：券商β大，相对估值在底部时往往是右侧机会

第三步：判断风格（选哪类券商）

环境优选风格理由
牛市初期经纪型+互联网型弹性最大
牛市中后期综合龙头估值修复完成，业绩兑现
直接融资政策红利投行型长期α最强
整合周期整合主题+大主导方合并溢价
震荡市资管型+财富管理稳定的管理费收入

第四步：识别陷阱

陷阱1：用单季业绩外推全年
Q1业绩+50%不代表全年+50%。自营业务的Q1表现严重依赖股债走势，季度间方差极大。正确做法：拆解Q1业绩来源，判断自营增量的可持续性。
陷阱2：用历史估值中枢做锚
行业ROE中枢在下移，历史PE/PB中枢已经不适用。用2014年的估值锚看2026年的券商，会一直觉得"便宜"。正确做法：动态调整估值中枢，跟踪ROE趋势。
陷阱3：把β当α
90%的券商上涨都是板块β，不是个股α。选错风格不如直接买ETF。正确做法：先判断β方向，再选风格，最后选个股。
六、长期结构性变量：未来5-10年看什么
变量1：A股直接融资占比
当前A股直接融资/社融约15%（vs 美股70%）。股票市值/GDP约70%（vs 美国200%+）。
判断：A股直接融资还有3-5倍空间，但需要10-20年。投行业务是最确定的长期成长方向。
变量2：居民财富权益化
中国居民资产中权益/基金占比约10%（vs 美国40%）。公募基金规模/GDP约25%（vs 美国120%）。
判断：财富管理是结构性增长方向。但券商在这块的份额会被银行、第三方平台（蚂蚁、天天基金）持续蚕食。
变量3：监管中枢
监管对券商的态度长期是"做大做强主体、压低中间费率、防范金融风险"——头部券商受益（合并、牌照、资本），中小券商承压，自营业务被约束。
判断：行业马太效应会持续，前10家会拿到80%的利润，中小券商靠并购或被并购退场。
变量4：金融对外开放
外资全资券商已经全面进入（高盛、摩根士丹利、瑞银等）。主要冲击：大型IPO、跨境并购、机构经纪。
判断：外资不会颠覆A股券商格局（散户基础在本土券商），但会持续蚕食高端业务利润。

八、当前时点案例：2026-05 板块状态

套用第一步：β判断

处于"自营利润大年"的环境，板块整体应该有β收益。

估值判断
PE在历史低位但ROE也在低位，PB分位（35%）才是真实水位——估值是"合理偏低"而非"严重低估"。要看到真重估，需要ROE先反弹到8%+。

套用第三步：风格选择

优选风格当前最看好理由
综合龙头中信、华泰估值合理、ROE有韧性
投行型中金估值历史最低+合并预期+海外业务
整合主题型信达、未来的方正事件驱动溢价
谨慎对待互联网型（东财）估值仍贵、流量增长见顶

套用第四步：识别当前陷阱

三个当前陷阱
1. 不能用Q1+35%外推全年：自营贡献了60-70%增量，Q2若股市横盘则环比立刻下滑。
2. PE 0%分位不等于安全：ROE中枢若从7%→6%，PE 10x也不便宜。
3. 合并主题需要分主导方：买信达赚的是套利，买中金赚的是合并后协同——两者是不同生意。

当前时点的三个核心问题（待验证）

待验证问题
1. Q2半年报（2026-08）：自营能否延续，投行能否启动。
2. 中金+信达股东大会：合并主线第一个里程碑。
3. 行业ROE趋势：2026全年能否回到8%+，决定估值中枢能否上移。

十、读完这份文档之后你应该会的事
六项能力
1. 5分钟内判断β方向：套用第五节第一步的三个问题。
2. 判断估值是真便宜还是陷阱：看PB+ROE双因子，不只看PE分位。
3. 选对风格：根据当前环境从五种类型中挑。
4. 看懂任何一份券商财报：拆五业务线，重点看自营和投行。
5. 识别叙事陷阱：Q1业绩外推、历史估值锚、把β当α。
6. 跟踪长期变量：直接融资占比、居民财富权益化、监管中枢。

如果某个时点你拿不准，回到第七节的监控表，逐项打分即可。
